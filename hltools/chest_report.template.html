  1. py hltools/pak_extract.py extract data.cdb --pak "<Farever>\res.light.pak" --out analysis_out/cdb — the loot tables
  2. py hltools/build_map_assets.py (in FareverMeter) — only if the world map itself changed

The prefab dump in analysis_out/prefabs_map/ comes from res.map.pak and changes only when the world does. Every number on this page is baked in at build time — nothing here reads the game, so a page built before a patch will keep showing the old world without complaining. The data.cdb hash above is how you tell.
